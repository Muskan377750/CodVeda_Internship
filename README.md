## 📌 About the Internship

This repository contains the projects and tasks completed as part of my **Web Development Internship at Codveda Technology**.

The internship is structured into different levels, starting with fundamental web development concepts and progressing toward intermediate and advanced full-stack development.

Through these practical tasks, I am gaining hands-on experience in designing websites, creating responsive layouts, developing interactive web applications, working with JavaScript and modern frontend technologies, building backend APIs, managing databases, and implementing user authentication.
