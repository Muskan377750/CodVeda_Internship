## 📚 Internship Tasks

### 🟢 Level 1

#### Task 1 — Simple Static Website

* Built a multi-page static website.
* Used HTML5 for structure.
* Used CSS3 for styling.
* Added navigation bar, images, and footer.
* Implemented basic responsive design using media queries.

**Technologies:** HTML5, CSS3

#### Task 2 — Portfolio Webpage

* Created a personal portfolio webpage.
* Added introduction, skills, projects, and contact sections.
* Added custom styling, colors, fonts, and animations.

**Technologies:** HTML5, CSS3

---

### 🔵 Level 2

#### Task 1 — Responsive Web Design with Flexbox and Grid

* Created responsive layouts using CSS Flexbox.
* Used CSS Grid for organizing content.
* Implemented layouts for desktop, tablet, and mobile screens.

**Technologies:** HTML5, CSS3, Flexbox, CSS Grid

#### Task 2 — To-Do List Application

* Created an interactive To-Do List application.
* Added functionality to add, edit, complete, and delete tasks.
* Used Local Storage to preserve tasks after refreshing the browser.

**Technologies:** HTML5, CSS3, JavaScript, Local Storage

---

### 🔴 Level 3

#### Task 1 - Build a Full-Stack CRUD Application

• Set up a back-end server with Express or Django.
• Create a REST API to handle CRUD operations.
• Build a front-end with React or Vue that interacts with
the back-end API.
• Use a database (e.g., MongoDB, PostgreSQL) to store
data.
• Tools: Node.js, Express, or Django, React/Vue,
MongoDB/PostgreSQL.

#### Task 2 — User Authentication System

* Implemented user registration and login.
* Created backend APIs using Node.js and Express.js.
* Integrated MongoDB for storing user information.
* Used bcrypt for password hashing.
* Implemented JWT-based authentication.
* Added protected routes for authenticated users.

**Technologies:** Node.js, Express.js, MongoDB, Mongoose, JWT, bcrypt
