## 🌍 About GreenNest

**GreenNest** is an environmental awareness website created to encourage people to adopt simple and sustainable habits in their everyday lives.

The website focuses on an important idea:

> 🌱 **Small changes in our daily lives can create a big impact on our planet.**

GreenNest provides practical information about reducing waste, conserving natural resources, saving energy, recycling, sustainable transportation, and creating greener surroundings.

---

## ✨ Features

### 🏠 Home
A visually engaging landing page that introduces GreenNest and encourages visitors to explore sustainable living practices.

### 🌱 About
Explains the purpose, mission, and core values of GreenNest.

### ♻️ Eco Tips
Provides simple and practical sustainability tips, including:

- Carrying reusable bottles
- Saving electricity
- Using public transportation
- Reducing food waste
- Planting more trees
- Recycling properly

### 📩 Contact
A simple contact section where visitors can share their ideas, suggestions, and feedback.

## 🎨 Design

GreenNest uses a clean and nature-inspired interface with:

- 🌿 Green color palette
- ✨ Minimal and modern design
- 📦 Clean card-based sections
- 🔘 Interactive buttons
- 📱 Responsive layouts
- 🧭 Simple navigation
- 🎯 Clear visual hierarchy

The design keeps the interface simple so that the **environmental message remains the main focus**.
